# EcoRappTech

Sito ufficiale di EcoRappTech – 
EcoRappTech è un ecosistema di competenze che accompagna privati, imprese, Pubbliche Amministrazioni e organizzazioni del Terzo Settore lungo tutto il percorso della transizione energetica: dalla consulenza alla progettazione, dall'ingresso nelle Comunità Energetiche allo sviluppo di impianti, dalla sicurezza energetica alla gestione e valorizzazione del patrimonio immobiliare ed energetico.

**Target:** Privati · Aziende · Terzo Settore · Pubblica Amministrazione

**Sito live:** https://ecorapptech-cloud.github.io
